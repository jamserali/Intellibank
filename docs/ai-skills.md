# AI skills

Skill descriptions are reusable workflows, separate from executable MCP tools. They should select read-only tools and summarize returned data; they do not confer permissions or independently establish financial facts.

1. **Client analysis:** resolve a client, retrieve client details, investments and P&L, then summarize exposure and profitability.
2. **Profit & loss analysis:** retrieve bank/client P&L and relevant time series; distinguish recognized net profit, realized P&L, unrealized P&L and economic return.
3. **Portfolio analytics:** retrieve portfolio allocation/performance and sector exposure; clearly state reporting date and currency.
4. **Client ranking:** use API-calculated top/bottom results and disclose the ranking metric; report tie/zero-capital conventions from the backend.
5. **Financial reporting:** retrieve period-aware metrics and produce structured summaries; label estimates as estimates.

Never invent quantitative data when a tool is unavailable or returns an error. Ask for clarification when entity names or periods are ambiguous. Explain general financial terminology separately from client-specific factual claims.
